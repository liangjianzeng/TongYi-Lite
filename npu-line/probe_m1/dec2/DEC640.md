# DEC640 —— prefill 终态 KV → decode 续链（NC=640 pad + 逐步 mask）

2026-11-11 G1 收官：真对话 prefill（pre2 终态 cache）→ decode 8 步贪心续链，740 设备
**8/8 cos=1.0000 / argmax 一致 / top8 8/8**（双向量：80-era 真对话 EOS 退化链 + 72-prompt
有意义链"清晰完整的回答。技术讨论应"）。背景：HTP S=1 attention 内核在 K=513 非对齐列 ×
特定 cache 数据（eos-heavy）probs 均匀化塌缩（坑 51）；NC=640（512 真值 + 128 零 pad）对齐
后须**逐步 mask**（坑 52：roll 使零 pad 窗每步左移一行，第 t 步 mask 注意力列
`[512-t .. 639-t] = -1e4`，新 token 列 640 常开）。

## 复跑入口（WSL 侧 python 均 `wsl -d Ubuntu-22.04 -- bash -c "bash/python3 /mnt/..."`）

1. 导出+stage：`bash mcp5_83_nc640_export.sh`（DEC_NC=640，42 图 → `mcp5_dec2_640/mcp5_nc640_l{k}.onnx`）
2. 批量 build：`PARA=2 bash mcp5_84_batch_nc640.sh 0 41`（→ serve_dec/nc640_l{k}_ctx.bin）
3. manifest：`python3 mcp5_84g_gen_nc640_manifests.py`（amask 用 `g_am640_t{t}.raw` 逐步展开）
4. 备料（任选向量）：
   - 80-era 真对话：`python3 mcp5_80_real_decode_prep.py`（feeds/refs）+
     `python3 mcp5_82_pad_caches.py`（d2q 终态 512→640 → d2e640_*，(s,hd,kv) 尾零 pad）
   - 72-prompt：`python3 mcp5_72_real_prep.py` + pad d2e_kc{i}/vc{i} → d2e640b_*（同 pad 法）
5. 逐步 amask：`python3 mcp5_87_gen_am640_steps.py`（g_am640_t{0..7}.raw，641 fp16）
6. 设备链：`SKIP_BIG=1 bash mcp5_85_run_nc640.sh`（首发去 SKIP_BIG 推 ctx/cache；**启动脚本内
   `cp -f d2e_hs0.raw d2e_hs_t0.raw` 规范化 t0 reseed——stale t0 残留是隐形毒药，坑 53**）
7. 判分：`python3 mcp5_80j_judge.py`（dev/d2e_logits_t{t}.raw vs d2e_ref_logits_t{t}.npy）

## 排障工具（定罪阶梯，分钟级 host 优先）

- `mcp5_86_ort_nc640.py [A|B|C|D|Z]`：**协议层仲裁**（host ORT 全链 vs HF refs）。
  变体 A=derived（roll+mask[512-t..639-t]）是唯一 PASS 的协议。跨 prompt 配对错/协议错
  在此现形，省设备小时。
- `mcp5_86b_layerdiff.py`：nc640 图(mask) vs dec2-512 图同输入（图等价定罪，1 层）。
- `mcp5_88*`：单层真 mask 设备 vs ORT（同字节输入，注意 knew 输出 raw 序 = (hd,kv)）。
- `mcp5_89_layer_sweep_prep.py`+`launch_sweep.sh`：42 层逐层设备 vs ORT（ORT-clean 输入，
  须 3 进程分片，单进程 >24 ctx contextCreate 0x3ea OOM）。
- `mcp5_90_chain_sweep.py`+`launch_chsw.sh`：链式自喂（设备喂设备）+ 尾巴单测——
  隔离"逐层无罪、链级有罪"类 bug（本次揪出 reseed t0 残留）。

## G4 自回归闭环（无 HF 在环）

`mcp5_91_autoreg.py`（WSL 侧跑，adb.exe 为 Windows 二进制——push/pull 一律 `E:\wsl_stage\...`
Windows 路径，坑 33 同款）：每步 `./launch_nc640_step.sh STEP`（gate counter 预置 `3*STEP`——
gate target 是绝对步号 gn·t+gid 而 t=CR5_T0，counter 从 0 起必死锁，坑 55）→ 三进程 DONE →
拉 logits → argmax → 主机 embed（safetensors 读 `model-00000-of-00001.safetensors`，bf16 需
`.to(torch.float16)`，坑 38）→ 推下一步 `d2e_hs_t{t}.raw` → 下一步；cache 由 CR5_ROLL_SAVE
跨启动持久化。判分：设备自选 token 序列 == HF greedy（72-prompt 向量 8/8
[62598,26619,46436,15343,396,5020,18219,1753]「清晰完整的回答。技术讨论应」PASS）。
跑前 driver 自带 pristine caches 重推（ROLL_SAVE 会污染设备 cache 文件）。
