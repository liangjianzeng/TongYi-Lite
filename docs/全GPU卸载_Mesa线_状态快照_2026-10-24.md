## 一屏结论（6 条，2026-10-20~21 裁决链，全部为可信口径）

1. **K40 裁决级 A/B：Mesa 全 GPU decode ≈ CPU bank 的 17.5–20%**（CPU 3.14 / MESA_ASYNC 0.55 /
   MESA_FLUSH1 0.63 t/s；安静态 loadavg 0.21、交错 3 轮、冷却 90s、trace-off、env 指纹齐备）。
   临时裁决，附五条可推翻条件（见 L3 裁决文档）。
2. **提交层已封死**：async 330 IB/token vs flush1 4100 IB/token 同为 0.6 t/s ⇒ 提交税天花板
   ≤15%，翻盘需 13× ⇒ **P5（整图单提交）永久降级**，不再投入。
3. **真凶候选换人（头号嫌疑）**：真实生产 decode 图 207 形状中 **87 个（42%）每 token 落 CPU**，
   其中 **80 个是 fork 自己的 `MAP_CUSTOM1 ffn_moe_slots`**（ggml-opencl 无实现）+ 路由
   `MUL_MAT_ID` 4 形状 ⇒ 每 token 数十次 GPU↔CPU 往返。**CPU 回落往返成本至今未量化**
   （需 third_party/llama.cpp 插桩，按仓库规矩需人接手）。
4. **专家 I/O 排除出关键路径**：读量 ÷5.6（DECODE_WINDOW=64+ROUTE_KEEP=1）只换来 +6%；
   P8 十腿 A/B 采纳 `DECODE_WINDOW=64 + ROUTE_KEEP=1`（+5.9%、读量 −82%）。
5. **gen7（830）async 病灶只剩一条候选：Mesa BO/ring 复用**（NGL 二分钉在 2→3 层边界；
   融合 race 四腿判负；FD_* 免重编开关扫完只有逐 op flush 能救）。830 自 10-20 起用户停用，
   放行后一条 `run_mesa_matrix`（~50 分钟）补齐计时半边。
6. **P3 根因钉死 + 补丁入库待自建构**：rusticl 藏 `cl_khr_subgroups`（IFP 写死 false），
   两行补丁 `third_party/mesa-kgsl/patches/0001-rusticl-advertise-cl_khr_subgroups.patch`；
   ALLOW_NO_SUBGROUP / FAKE_QCOM_REQD 两降级开关均承重。
