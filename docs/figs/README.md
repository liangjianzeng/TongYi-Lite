## 改内容 / 重新出图

1. 编辑 `../三步走-9页.html` 里的 9 个 `.pg`（每个 = 一页）
2. `_probe/deck_harness.html` 以 **390×844 iframe** 固定视口加载，右侧探针报 `FITS` / `OVERFLOW +N`
3. 无头 Chrome：`--headless=new --force-device-scale-factor=2 --window-size=700,844`
4. `sharp` 裁 `x:0..780` → `mobile/NN-主题.png`
5. 主题切换：HTML 支持 `?theme=light` / `?theme=dark` 显式覆盖（截图用），默认跟随系统

⚠️ **三个坑（都踩过）**
- Windows 无头 Chrome **窗口最小宽度约 492 px**。要验 390 px 手机宽度**必须用 iframe 包一层**，直接 `--window-size=390` 只是把 492 宽的布局裁到 390，看着像横向溢出，其实是假象。
- `.pg` 有 `overflow:hidden`，必须给卡片 `flex-shrink:0`，否则内容被压扁时 `scrollHeight` 不增长，探针测不出真实溢出。
- 本机系统偏好是**深色**，`@media (prefers-color-scheme:dark)` 会压过默认浅色；要出浅色图必须用 `?theme=light`（`body.lt` 权重高于 `@media`）。`--blink-settings=preferredColorScheme` 实测不可靠。
