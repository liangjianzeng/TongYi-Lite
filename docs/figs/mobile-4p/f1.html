三步走大方案 · 全景总纲

从同构 fork 到 手机端侧 35B-A3B

① 5060Ti 同构 fork 通透原理 → ② DGX 异构 ARM 统一内存特定优化 → ③ 手机端侧承载 Qwen3.6-35B-A3B。②与③同族——CPU/GPU 抢同一条 LPDDR5X，方法论迁移率远高于①。
同构立原理 异构证边界 端侧收口 端侧不做投机（负收益） 权重不全量常驻

两个前提（与①②相反）

前提 A
端侧不做投机
投机在端侧是负收益，与①②的 MTP 结论相反
前提 B
权重不全量常驻
常驻 3G + 热集 3–3.5G + 冷专家 5.06G 落 UFS
ONE LINE

①差一次 GPU 窗口 · ②差一次 nsys 测量 · ③P0+P1 一两天可判死

三步共用一套「专家流式 + 热缓存 + 钉页」机制血脉：同构立住原理，异构量出边界，端侧把它压在 16G 内存与 UFS 带宽的地板上做终局验证。
