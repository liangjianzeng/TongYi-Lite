内核缺口与绕行

mul_mat_id（MoE）在 Adreno 830 上全量化数值损坏

test-backend-ops 实锤：q4_0 ERR≈0.4 / q4_K ERR≈0.9+NaN / mxfp4 abort —— vendored 版与上游 master 同挂，属驱动级 bug。dense Q4 正常，故以 dense loop（host 侧专家循环）绕行中。
关键洞察：dense loop 与量化类型解耦 ⇒ 任何新类型只要做出 dense GEMV，MoE 自动继承同一条路（IQ2/Q2 因此可行）。自研内核仍需过 test-backend-ops 数值门（自研不免疫驱动 bug）。
VERDICT

评级 中等 · 乐观 17–20 / 悲观 6–9 t/s

差别只在门控条件：冷专家命中不 stall。热集覆盖仅 ~35.5% 是最大失真点 ⇒ 一切机制成败押在「miss 后的 UFS 读被 attention 算力藏住」。参考锚点：8 Gen5 至尊 + 16G 上 35B-A3B CPU 解码目测 20 出头（用户口径，未上机实测）。
