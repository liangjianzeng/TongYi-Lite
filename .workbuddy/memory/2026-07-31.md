## 重构：模型列表改为 JSON 配置文件驱动（用户指出"写死代码"问题）
- **用户质疑**：模型下载列表不该写死在 `builtInModels()`，后续扩展要反复改代码。
- **改动**：
  - 新增 `assets/models_catalog.json`，把全部 10 个模型迁移为数据（id/name/type/mirrors/sizeGB/sizeMBDisplay/recommended/minRamMB/sha256Hash）。
  - `pubspec.yaml` flutter 段注册 `assets: - assets/models_catalog.json`。
  - `lib/models/model_info.dart`：删除写死的 `builtInModels()`；`ModelConfig`/`MirrorEntry` 增加 `fromJson`，新增 `modelTypeFromJson`。
  - 新增 `lib/models/model_catalog.dart`：`ModelCatalog.load()` 优先可选远程 URL（`remoteUrl` const，默认 null）再回退打包 JSON，带内存缓存。
  - `lib/services/model_manager.dart`：改为 `init()` 调 `ModelCatalog.load()` 填充 `_models`；getters 返回 `_models`。
  - 删除无用的重复类 `lib/models/model_manager.dart`（与 services 版重复，且无人引用）。
  - `lib/services/download_service.dart` `resume()` 与 `lib/providers/download_provider.dart` `resumeDownload` 改用 `ModelManager().getModel(id)`，不再 `builtInModels()`。
  - `lib/main.dart`：`runApp` 前 `await ModelManager().init()`，保证 UI 直接有数据。
  - README「支持的模型」改为指向 JSON，并补「如何新增模型」+ 可选远程热更新说明。
- **结论**：加模型 = 改 JSON（可选远程热更新免发版），不再碰代码、不重编译。
- 沙箱无 Flutter SDK，未能 `flutter analyze`；已逐文件核对依赖无循环引用、无残留 `builtInModels` 调用。真机首次构建需 `flutter pub get` 后验证。
